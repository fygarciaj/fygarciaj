### 👨‍💻 Sobre mí
Soy un **Desarrollador Full-Stack y Arquitecto de Software** con base en Valledupar, Colombia. Mi enfoque principal es construir soluciones eficientes y escalables mediante lógica sólida, arquitecturas robustas y las mejores prácticas de desarrollo. Me especializo en transformar problemas complejos en código limpio, funcional y mantenible.

- 🔭 Actualmente trabajando en proyectos con **ReBootSystem** y desarrollando soluciones innovadoras en IA y salud digital.
- 🌱 Aprendiendo constantemente sobre Inteligencia Artificial, Arquitectura de Microservicios y tecnologías emergentes.
- 💼 Experiencia en desarrollo de sistemas de gestión clínica, plataformas educativas y automatización.
- 💬 Pregúntame sobre: TypeScript, Python, Laravel, NestJS, Arquitectura de Software, IA y Machine Learning.
- ⚡ Dato curioso: Creo firmemente que la programación es el arte de resolver problemas que no sabías que tenías.

### 🚀 Proyectos Destacados

#### 🏥 [DentWise](https://github.com/fygarciaj/dentwise)
Sistema de gestión para clínicas dentales desarrollado con TypeScript. Plataforma integral para administrar pacientes, citas, tratamientos y registros médicos.

#### 🏥 [Klinik Laravel API](https://github.com/fygarciaj/klinik-laravel-api)
API backend para un sistema moderno y eficiente de gestión de clínicas. Desarrollado con Laravel, maneja pacientes, doctores, citas, finanzas y más.

#### 🎓 [PTU Learning Platform](https://github.com/fygarciaj/ptu-learning-platform-back)
Backend de plataforma educativa desarrollada con TypeScript y NestJS. Sistema completo de gestión de aprendizaje con arquitectura de microservicios.

#### 🧠 [AI Project Gallery](https://github.com/fygarciaj/AI-Project-Gallery)
Repositorio que contiene proyectos de Inteligencia Artificial incluyendo Machine Learning, Deep Learning y IA Generativa. Explora técnicas y conceptos avanzados.

#### 🎤 [VoxCPM](https://github.com/fygarciaj/VoxCPM)
Proyecto de procesamiento de voz con Python, enfocado en tecnologías de reconocimiento y síntesis de voz.

#### ⚙️ [NestJS Service Template](https://github.com/fygarciaj/nestjs-service-template)
Template para nuevos servicios basados en NestJS con las mejores prácticas y listo para producción.

#### 🏗️ [Microservicios Base NestJS](https://github.com/fygarciaj/microservicios-base-nestjs)
Arquitectura base de microservicios desarrollada con NestJS y TypeScript, ideal para proyectos escalables.

#### 🎨 [Lottie Extract](https://github.com/fygarciaj/lottie-extract)
Herramienta en JavaScript para trabajar con animaciones Lottie, facilitando la extracción y manipulación de elementos.

#### 📸 [SnapAI](https://github.com/fygarciaj/snapai)
CLI con inteligencia artificial para generar iconos de aplicaciones para desarrolladores de React Native y Expo usando los últimos modelos de OpenAI.

#### 🎬 [Video Transcoder Service](https://github.com/fygarciaj/Video-Transcoder-Service)
Sistema end-to-end de transcodificación de video que genera eficientemente diferentes resoluciones de videos subidos, mejorando la accesibilidad y rendimiento.

#### 📝 [MVC Laravel Citas GMHR](https://github.com/fygarciaj/mvc-laravel-citas-gmhr)
Sistema de gestión de citas médicas para centros que realizan reconocimientos médicos para empresas, desarrollado con Laravel.
